## Validation Approach

All AI-assisted code and recommendations were:

- Executed locally where applicable
- Tested against the actual Edinburgh dataset
- Reviewed for correctness and assignment fit
- Modified where necessary
- Documented when rejected or substantially changed

The candidate retains ownership of:

- Final interpretation of findings
