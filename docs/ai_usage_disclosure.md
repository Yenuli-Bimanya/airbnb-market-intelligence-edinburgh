## AI-Assisted Activities

### Activity 001: Initial Project Planning

**Purpose:** Understand the assignment and determine an achievable one-week project scope.

**AI Contribution:** Suggested an end-to-end data engineering project structure and implementation sequence.

**Candidate Validation:** Recommendations were reviewed against the official assignment requirements before adoption.

**Candidate Modifications:** The scope was adjusted to prioritize a strong single-city pipeline rather than superficial multi-city analysis.

### Activity 002: Environment Setup

**Purpose:** Configure Python, VS Code and the project virtual environment.

**AI Contribution:** Provided installation and PowerShell setup instructions.

**Candidate Validation:** Commands were executed locally and Python paths were verified manually.

## Validation Approach

All AI-assisted code and recommendations will be:

- Executed locally
- Tested against the actual dataset
- Reviewed for correctness
- Modified where necessary
- Documented when rejected or substantially changed
